# Telegram Bot для продажи цифровых товаров

Полнофункциональный Telegram-бот на Python (aiogram 3.x) для продажи цифровых товаров с поддержкой криптоплатежей, реферальной системы и технической поддержки.

## 🚀 Основные функции

- 🛒 **Многошаговый процесс покупки** (3 шага: выбор количества → оплата → выдача)
- 💳 **Интеграция с платежными системами**:
  - CryptoBot API
  - Криптовалюта (USDT TRC20/BEP20, TON, ETH)
- 👥 **Реферальная система** с персональными ссылками и статистикой
- 🆘 **Техническая поддержка** с системой тикетов
- 📊 **Админ-панель** с экспортом статистики /admin
- ✅ **Автоматическая выдача товара** после подтверждения платежа
- 📝 **Логирование** всех действий
