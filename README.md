# Telegram Bot для продажи цифровых товаров

Полнофункциональный Telegram-бот на Python (aiogram 3.x) для продажи цифровых товаров с поддержкой криптоплатежей, реферальной системы и технической поддержки.

## 🚀 Основные функции

- 🛒 **Многошаговый процесс покупки** (3 шага: выбор количества → оплата → выдача)
- 💳 **Интеграция с платежными системами**:
  - CryptoBot API
  - Криптовалюта (USDT TRC20/BEP20, TON, ETH)
- 👥 **Реферальная система** с персональными ссылками и статистикой
- 🆘 **Техническая поддержка** с системой тикетов
- 📊 **Админ-панель** с экспортом статистики
- ✅ **Автоматическая выдача товара** после подтверждения платежа
- 📝 **Логирование** всех действий

## 📋 Требования

- Python 3.10+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- (Опционально) CryptoBot Token для приема платежей через CryptoBot

## 🛠 Установка

1. **Клонируйте репозиторий или скачайте файлы**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте файл `.env` на основе `.env.example`:**
```bash
# Скопируйте пример
cp .env.example .env

# Отредактируйте .env и укажите свои данные
```

4. **Настройте `.env` файл:**

Минимально необходимые настройки:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789
```

Полный список настроек см. в `.env.example`

5. **Создайте необходимые папки:**
```bash
mkdir -p data/screenshots
```

6. **Запустите бота:**
```bash
python main.py
```

## ⚙️ Конфигурация

Все настройки находятся в файле `.env`. Основные параметры:

### Обязательные:
- `BOT_TOKEN` - токен Telegram бота
- `ADMIN_IDS` - ID администраторов через запятую

### Опциональные:
- `CRYPTOBOT_TOKEN` - токен CryptoBot API (если используете)
- `SUPPORT_MANAGER_ID` - ID или username менеджера поддержки
- `CHANNEL_ID` - ID канала с отзывами
- `USDT_TRC20`, `USDT_BEP20`, `TON`, `ETH` - адреса криптокошельков
- `PRICE_1_20`, `PRICE_20_50`, `PRICE_50_100` - цены за единицу товара
- `REFERRAL_PERCENT` - процент реферальной системы (по умолчанию 15%)

## 🎮 Использование

### Для пользователей:

1. Запустите бота командой `/start`
2. Выберите "🛒 Купить аккаунты"
3. Выберите количество или готовый пакет
4. Выберите способ оплаты
5. Оплатите и получите товар автоматически

### Для администраторов:

1. Используйте команду `/admin` для доступа к админ-панели
2. Доступные функции:
   - 📊 Статистика (с экспортом в файл)
   - 👤 Управление пользователями
   - 📦 Управление заказами
   - 💸 Проверка платежей
   - 🎁 Выдача товара
   - ✉️ Рассылка сообщений

## 🔧 Настройка платежей

### CryptoBot:

1. Создайте бота в [@CryptoBot](https://t.me/CryptoBot)
2. Получите API токен
3. Укажите токен в `.env`: `CRYPTOBOT_TOKEN=your_token`

### Криптовалюта:

1. Укажите адреса ваших кошельков в `.env`
2. Пользователи будут отправлять платежи на эти адреса
3. Администратор проверяет платежи вручную через админ-панель

## 📊 База данных

Бот использует SQLite для хранения данных. Таблицы:

- `users` - пользователи бота
- `orders` - заказы
- `payments` - платежи
- `referrals` - рефералы
- `tickets` - тикеты поддержки

База данных создается автоматически при первом запуске.

## 🔐 Безопасность

- Все чувствительные данные хранятся в `.env` файле
- `.env` файл должен быть добавлен в `.gitignore`
- Не публикуйте токены и приватные ключи

## 📝 Логирование

Логи сохраняются в файл `data/bot.log` и выводятся в консоль. Уровень логирования настраивается через `LOG_LEVEL` в `.env`.

## 🐛 Решение проблем

### Бот не запускается:
- Проверьте, что указан `BOT_TOKEN` в `.env`
- Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`
- Проверьте права доступа к папке `data/`

### Платежи не работают:
- Для CryptoBot: проверьте правильность токена
- Для криптоплатежей: убедитесь, что указаны адреса кошельков

### Админ-панель недоступна:
- Проверьте, что ваш ID указан в `ADMIN_IDS` в `.env`
- Получите свой ID у [@userinfobot](https://t.me/userinfobot)
