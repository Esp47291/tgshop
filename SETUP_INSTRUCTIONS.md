# 🚀 Инструкция по настройке бота

## Шаг 1: Получение токена бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "My Shop Bot")
   - Введите username бота (должен заканчиваться на `bot`, например: `myshop_bot`)
4. BotFather выдаст вам токен вида: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`
5. Скопируйте этот токен

## Шаг 2: Получение вашего ID администратора

1. Откройте Telegram и найдите бота [@userinfobot](https://t.me/userinfobot)
2. Отправьте команду `/start`
3. Бот покажет ваш ID (число, например: `123456789`)
4. Скопируйте этот ID

## Шаг 3: Настройка файла .env

1. Откройте файл `.env` в корне проекта
2. Замените `YOUR_BOT_TOKEN_HERE` на токен из шага 1
3. Замените `YOUR_ADMIN_ID_HERE` на ваш ID из шага 2

Пример:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_IDS=123456789
```

## Шаг 4: Запуск бота

1. Убедитесь, что установлены все зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите бота:
   ```bash
   python main.py
   ```

3. Если всё настроено правильно, вы увидите сообщение:
   ```
   База данных инициализирована
   Бот запущен!
   ```

## Шаг 5: Проверка работы

1. Найдите вашего бота в Telegram по username, который вы указали при создании
2. Отправьте команду `/start`
3. Если бот отвечает - всё работает! ✅

## Дополнительные настройки (опционально)

### CryptoBot (для автоматических платежей)

1. Откройте [@CryptoBot](https://t.me/CryptoBot) в Telegram
2. Создайте бота для приема платежей
3. Получите API токен
4. Добавьте токен в `.env`:
   ```env
   CRYPTOBOT_TOKEN=your_cryptobot_token
   ```

### Криптокошельки

Если вы хотите принимать платежи напрямую на криптокошельки:

1. Создайте кошельки для разных сетей (TRC20, BEP20, TON, ETH)
2. Добавьте адреса в `.env`:
   ```env
   USDT_TRC20=your_wallet_address
   USDT_BEP20=your_wallet_address
   TON=your_wallet_address
   ETH=your_wallet_address
   ```

## Решение проблем

### Ошибка: "BOT_TOKEN не установлен"
- Проверьте, что файл `.env` существует в корне проекта
- Убедитесь, что токен указан правильно (без пробелов, кавычек)

### Ошибка: "ModuleNotFoundError"
- Установите зависимости: `pip install -r requirements.txt`

### Бот не отвечает
- Проверьте, что токен правильный
- Убедитесь, что бот запущен (запустите `python main.py`)
- Проверьте логи в файле `data/bot.log`

### Админ-панель не работает
- Убедитесь, что ваш ID указан в `ADMIN_IDS` в `.env`
- Проверьте ID через [@userinfobot](https://t.me/userinfobot)

## Готово! 🎉

Теперь ваш бот готов к работе. Вы можете:
- Протестировать покупку через меню бота
- Использовать команду `/admin` для доступа к админ-панели
- Настроить дополнительные параметры в `.env`
